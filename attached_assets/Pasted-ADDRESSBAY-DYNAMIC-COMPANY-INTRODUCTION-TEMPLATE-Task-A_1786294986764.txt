ADDRESSBAY — DYNAMIC COMPANY INTRODUCTION TEMPLATE

Task:
Add a dynamically generated company introduction paragraph at the TOP of the company detail page, immediately ABOVE the existing "Overview" section.

IMPORTANT:
DO NOT redesign the page.
DO NOT change the existing company card, header, navigation, buttons, colors, spacing, typography, Overview section, tables, sections, footer, or any existing functionality.
DO NOT remove or rename any existing fields.
DO NOT change the current page structure except inserting this new paragraph section immediately before the existing Overview section.

The only new UI/content should be this dynamically generated company introduction.

==================================================
1. UNIVERSAL TEMPLATE
==================================================

The template must be generic and work for companies from:

- India
- United States
- United Kingdom
- Australia
- Singapore
- Future countries

Do NOT hard-code Indian terminology such as CIN, ROC, MCA, PIN code, etc.

Use the actual database field values and the country's applicable registration terminology.

Generate ONE natural-language paragraph using the available company data.

Template logic:

"{{company_name}} is a {{entity_type}} registered in {{city}}, {{region}}, {{country}}. The company was {{registration_action}} on {{registration_date}} and is registered with {{registration_authority}} under {{registration_number_label}} {{registration_number}}. Its current registration status is {{company_status}} and its registered or principal business address is {{registered_address}}."

Where:

company_name
= company legal/business name from database

entity_type
= company/entity type from database

city
= city/locality field

region
= state/province/region/county equivalent

country
= country

registration_action
= country/entity appropriate wording such as:
- incorporated
- registered
- established

registration_date
= incorporation/registration date

registration_authority
= relevant authority

registration_number_label
= country-specific label:
India → CIN
USA → Entity/File/Registration Number as applicable
UK → Company Number
Australia → ACN/ABN as applicable
Singapore → UEN
etc.

registration_number
= actual registration number

company_status
= actual status

registered_address
= actual registered/principal address

==================================================
6. MISSING DATA RULE
==================================================

NEVER display:

undefined
null
N/A
Unknown
empty commas
broken sentences
placeholder text

If a field is missing, intelligently omit that part of the sentence.

For example, if registration authority is unavailable:

BAD:
"The company was incorporated on 2 July 1981 and is registered with undefined under CIN..."

GOOD:
"The company was incorporated on 2 July 1981 under CIN L72200KA1996PLC019635."

If the registration number is unavailable, omit the registration-number sentence completely.

The paragraph must always remain grammatically correct.

The mapping should determine:

registration number label
registration authority label
registration action
address terminology
region terminology
status terminology

India:
registration number → CIN

authority → relevant Australian registration authority

Do NOT assume every country uses the same registration number or authority.
