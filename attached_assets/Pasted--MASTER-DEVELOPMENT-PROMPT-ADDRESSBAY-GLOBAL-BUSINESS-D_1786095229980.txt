# 18. MASS DATA IMPORT

This is one of the highest-priority technical areas.

The application must support very large datasets.

Current target:

1.3 GB+ XML

Potentially millions of records.

Do NOT load the entire XML file into Node.js memory.

Do NOT use:

readFile()

to load the complete XML document into memory.

Do NOT parse millions of records into one giant JavaScript array.

Use streaming XML parsing.

Preferred architecture:

Upload file to disk
→ create import job
→ stream parser
→ normalize record
→ validate
→ batch records
→ PostgreSQL bulk insert/upsert
→ clear batch
→ continue

Batch size should be configurable, for example 1,000–5,000 records, and benchmarked against the actual database.
